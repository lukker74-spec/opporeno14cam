# Reno14 FreshCam v12.0 (Ghiera Zoom 120x + Tasto AI Unificato + Impostazioni Foto/Video + Autoscatto + Anteprima Galleria)

- **Tasto Impostazioni sempre fisso** in alto a destra con sezioni separate **Foto** (qualità JPEG, OIS+EIS, GPS, griglia) e **Video** (`4K UHD`, `1080p Full HD`, `720p HD`).
- **Unico tasto AI** con 7 stati (`AI Off`, `Locale Bassa/Media/Alta`, `Cloud Bassa/Media/Alta`).
- **Autoscatto (Timer)** integrato (`Off`, `3s`, `5s`, `10s`) con conto alla rovescia sul mirino.
- **Anteprima reale dell'ultima foto** nel cerchio Galleria.
- **Selettore di zoom a ghiera rotante** fino a `120x` che scompare automaticamente dopo 2 secondi di inattività.
