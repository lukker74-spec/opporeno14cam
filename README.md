# Reno14 FreshCam v2.0 (Super-Resolution Generativa a Scelta)

Include il supporto per **Super-Resolution Generativa** attivabile o disattivabile dall'utente (tasto rapido **SR: OFF / SR: ON** in alto e interruttore nelle Impostazioni), basato su runtime LiteRT (`com.google.ai.edge.litert:litert:1.0.1` se inserisci `super_res_gan.tflite` in `app/src/main/assets/`) con fallback locale di sintesi direzionale dei dettagli.
